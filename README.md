# Homebrew tap for CleiMesh

```sh
brew install cleitonaugusto/cleimesh/cleimesh
```

Installs the release binary for your platform (macOS or Linux, Intel or ARM), checked against its published SHA-256. CleiMesh puts MCP servers behind signed tokens: what your agent reads can't decide what it does. Project: https://github.com/cleitonaugusto/cleimesh
